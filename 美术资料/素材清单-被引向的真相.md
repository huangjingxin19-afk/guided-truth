# 素材清单 —《被引向的真相》

**日期：2026-11-14**
**依据：** 目标文件夹 4 份文件（开发草案、主线方案五、剧情定稿、开发计划）+ GitHub 仓库 `huangjingxin19-afk/guided-truth` 最新代码（`gotdot/`，2026-11-14 22:14 提交，Android 1.0.2/1.0.3）
**现状：** 仓库里全是色块占位，没有正式美术、音频、中文字体。102 只有墙 / 地板 / 黑板 / 长桌 / 抽屉柜的 Polygon 色块，林禾是色块人形、无行走帧；道具只有脚垫、轮痕；证据只有这两条。其他房间、其余 5 人、对话、章节逻辑都未进仓库。
**用途：** 打勾用。`[ ]` 未开始，`[~]` 已有占位 / 临时，`[x]` 素材制作完成并交付（真机验证属于程序接入后的验收，不计入本清单的完成状态）。
**通用规范（开发计划）：** 像素图统一比例、透明 PNG、近邻缩放；角色统一尺寸、脚底对齐；家具同时设摆放点、占地、点击范围；文件名固定，如 `room102_desk`；每件素材记录文件名、用途、来源、授权、署名、修改内容。
**通用规范补充（2026-11-14 修订）：**
- 画布与比例：在 A5 样板阶段明确 960×540 是游戏显示画布还是原始绘图尺寸，并确定统一像素密度。
- 独立素材：可移动、可交互或会遮挡人物的物品，原则上独立导出透明 PNG，不画死在背景里。
- 动态状态：只为外观确实改变的部分制作变体；程序通过位置移动就能完成的变化，不需要重复绘图。
- 交付标准：每项交付包含正式素材、必要状态、可编辑源文件及来源授权信息；由素材负责人标记制作和交付完成。
- 音频制作规范：门槛与车板优先自录；其余先试听授权清楚的短音效。

## 画风参考 — 折中版（2026-11-14 定调，仅供参考）

![折中版 102 画风参考](画风参考-折中版102.webp)

- **只参考画风，不锁定其他：** 参考《黑暗侦探》The Darkside Detective / 《石河伦吾的朋友们》下半部分像素画面，不是低像素 Q 版小人（《回家早一点》那种）。图中具体色调、亮度、饱和度、黑板字、门牌文字、人物长相、桌上小物件，**都不作数**，后续根据剧情、章节、白天 / 夜晚再优化。
- **定调（骨架）：** 中高像素、人物高个子接近真人比例（48–64 像素，能看清脸）、像素小而密、边缘硬、纯色块、无模糊 / 无抗锯齿、Godot 导入用 Nearest（最近邻）放大。
- **减细节（省工作量）：** 场景只画重点，墙 / 地板用大色块，能互动的桌子、抽屉、门牌才细画；人物衣服少画褶皱；氛围靠灯光和暗角，不靠堆满小物件。动画只给林禾做全套，其他人只画站立 + 1 个关键动作。
- **这张图本身：** AI 生成的样图，不是最终美术，不能直接放进游戏使用。先按这个标准画 A5 样板（102 + 林禾），确认后再铺开其他房间。
