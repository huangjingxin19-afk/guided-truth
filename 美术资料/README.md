# 《被引向的真相》美术资料

## 开始制作

1. 先看[林禾画风参考](linhe-clean-128px-x6.png)定画风气质，再看[林禾四向行走定版](林禾-四向行走定版/README.md)的成品帧对齐人物造型与规格（画布 72×108、人物高约 96–100、脚底基线约 y=104）。人物使用接近真人的修长比例、低饱和色块和硬边像素。场景沿用硬边和克制的材质配色，明暗与色温随场景光源调整。
2. 按[素材制作清单](素材清单-被引向的真相.md)的 A5 做 102 接入验证。用一张底图、独立长桌和定版林禾帧，核对绕行、遮挡和步速同步（人物大小已定版）。
3. 样板确认后按清单 C 类制作人物，再按 P0 起的优先级补齐场景、证物和音效。[剧情定稿](../被引向的真相-剧情定稿.md)用于核对道具、动作和线索。

## 人物素材

- **林禾**四向逐帧行走已定版（[林禾-四向行走定版](林禾-四向行走定版/README.md)，画布 72×108、脚底基线约 y=104）；站姿待按同一规格补交。各帧使用同一画布和脚底锚点。
- **其他五人**先交站姿，用体型、发型、肩线和衣服区分。推车、量凳、签收、递单、提袋和递谱架等按镜头补关键姿势，人物与手持道具分开交图。
- **交付**游戏图使用带真实透明通道的 PNG，动画附帧序。源文件和素材来源一起保留。林禾参考图带棋盘格，用于定画风。
