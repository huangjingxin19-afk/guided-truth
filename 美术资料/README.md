# 美术资料 — 只放设计文档和画风参考，不放开发代码

这个文件夹和开发项目是分开的，不要弄混：

- **开发代码在 `gotdot/`**：Godot 工程、脚本、场景、已接入的占位美术。改代码、改场景只动那里。
- **这里只放美术 / 设计文档**：素材清单、画风参考图。画画的人看这里，程序员接入正式美术时再按清单从这里取，不要把这里的图直接当游戏内素材导入。

## 这里有什么

- `素材清单-被引向的真相.md`：要画什么、按什么顺序画（P0 先画第一章）、每件素材的状态和规范。
- `画风参考-折中版102.webp`：画风参考图，只参考画风。图中具体色调、亮度、黑板字、门牌文字、人物长相、桌上小物件都不作数，后续根据剧情、章节、白天 / 夜晚再优化。这张图是 AI 生成的样图，不是最终美术，不能直接放进游戏使用。

## 不要在这里放的东西

- 不要放 `gotdot/` 里的代码、场景、脚本。
- 不要把正式游戏素材直接塞进来又不记在清单里；新素材先写进清单，再放进来。
