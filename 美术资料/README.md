# 《被引向的真相》美术资料

## 开始制作

1. 先看[林禾画风参考](linhe-clean-128px-x6.png)。人物使用接近真人的修长比例、低饱和色块和硬边像素。场景沿用硬边和克制的材质配色，明暗与色温随场景光源调整。
2. 按[素材制作清单](素材清单-被引向的真相.md)的 A5 做 102 样板。用一张底图、独立长桌、林禾侧面站姿和一组步行帧，确认人物相对门桌的大小、像素密度、绕行和遮挡。
3. 样板确认后按清单 C 类制作人物，再按 P0 起的优先级补齐场景、证物和音效。[剧情定稿](../被引向的真相-剧情定稿.md)用于核对道具、动作和线索。

## 人物素材

- **林禾**先做侧面站姿和逐帧步行，在 102 里看实际效果，再补齐其他朝向。各帧使用同一画布和脚底锚点。
- **其他五人**先交站姿，用体型、发型、肩线和衣服区分。推车、量凳、签收、递单、提袋和递谱架等按镜头补关键姿势，人物与手持道具分开交图。
- **交付**游戏图使用带真实透明通道的 PNG，动画附帧序。源文件和素材来源一起保留。林禾参考图带棋盘格，用于定画风。
