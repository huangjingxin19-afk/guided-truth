# 林禾 · 侧面（朝右）骨骼拆件 v2（纯像素图拆分）

拆分方式：**直接在参考图 `人物参考-林禾-原生128.png`（30×128 像素图）本身上按部件区域切分**，不经过任何高清图。每件的像素就是参考图原像素，静止重组与参考图逐像素 100% 一致，脸未做任何改动。高清拆件已删除，避免再被误当外观标准。

## 文件

## 注意
- 每件已向相邻部件扩了 2 像素的重叠副本（都是参考图原像素，藏在相邻部件下面，静止重组仍 100% 一致），小角度旋转不会露缝。
- 摆动角度别太大：胳膊只有约 4 像素宽，大角度旋转像素会撕裂，走路摆幅先控制在 ±20° 内试，主要靠腿摆 + 身体上下浮动。
- 轮廓边缘有约 0.3% 混了棋盘格的浅色像素，深色背景上动起来可能带一点浅边，绑骨实测后再看要不要描边。
- 远侧胳膊只是一条薄边，走路时建议基本不动或只做很小摆动。
- 左侧 = 本套水平翻转，不用另做。
- 还缺：正面、背面各一张站立像素整图（同样直接在像素图上拆）。
- 若实测旋转质感不能接受，备选路线：骨骼摆好姿势 → 导出帧图 → 按参考图颜色清理 → 游戏里播帧。
