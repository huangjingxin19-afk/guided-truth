# 林禾：统一像素风四向行走素材包

基于最新人物参考稿制作的 4 方向 × 4 帧重制素材。为了保持四向一致，16 帧采用统一调色板、原始像素网格、透明背景、固定画布和脚底基准。**它们是新的美术重制稿，并非你早期右行走 GIF 的逐像素编辑**；导入正式游戏前仍建议在场景中检查转向、脚底和马尾细节。

## 使用哪个版本？

- `game_96px/`：建议优先用于你当前 Godot 960×540 项目。每帧 **72×108 px**，人物视觉身高约 **96–100 px**，与前面讨论的 96px 大小接近。直接 `scale=1`，使用 Nearest 过滤。
- 根目录 `right/`, `left/`, `front/`, `back/`：较大尺寸源图，每帧 **96×144 px**（人物约 **128–133 px**），用 `scale=0.75` 可得到上面的游戏尺寸。

## 素材结构

- 全向表：`game_96px/linhe_all_4x4.png`，288×432，横向4帧，纵向按「右→左→前→后」排列。
- 每方向表：`game_96px/linhe_{right,left,front,back}_4x1.png`，288×108，4帧。
- 独立帧：`game_96px/{direction}/{direction}_walk_01.png` 至 `_04.png`，RGBA 真透明。
- 大版素材：根目录独立帧 96×144；4x1 表 384×144；全向表 384×576。
- `*_preview.gif`：仅供预览，有深色背景，不建议直接用作游戏源素材。

## 动画及锚点

- 顺序：01 → 02 → 03 → 04 → 循环，每帧150ms，约6.67FPS。
- 各帧都固定画布和脚底基准，角色大版脚底约 Y=139，游戏96版约 Y=104；具体可用脚底落点作 AnimatedSprite2D offset。
- Godot 使用 CanvasItem.TEXTURE_FILTER_NEAREST（或材质导入最近邻）；尽量使用一致的画面缩放倍率。
- 面向左/右时，原画是独立朝向而非简单双向镜像；角色发型保持参考稿外观。

## 已知限制

这是一套对 AI 参考稿执行像素化、统一调色和自动抠图后的游戏测试素材，不是专业像素画师在 30×128 原始参考网格上逐格重画。总体像素规格统一，但近看仍可能有少数边缘像素与局部动作需要人工修整。游戏内目标身高如果必须**严格等于**96px，请手工逐格微调所有方向，不宜通过逐帧不同缩放来强行凑高度。
