# 林禾：四向行走定版素材

基于最新人物参考稿制作的 4 方向 × 4 帧重制素材。为了保持四向一致，16 帧采用统一调色板、原始像素网格、透明背景、固定画布和脚底基准。**它们是新的美术重制稿，并非早期右行走 GIF 的逐像素编辑**；导入正式游戏前仍建议在场景中检查转向、脚底和马尾细节。

> 2026-11-16 精简：本文件夹只保留游戏直接使用的版本。大尺寸源帧（96×144）、拼图版（4x4 / 4x1）和预览 GIF 已从仓库删除，需要时可从本仓库 git 历史（上传提交）或原始素材包恢复。

## 本文件夹内容

- `game_96px/{front,back,left,right}/{direction}_walk_01.png` 至 `_04.png`：独立帧，RGBA 真透明，每帧 **72×108 px**，人物视觉身高约 **96–100 px**。用于当前 Godot 960×540 项目，直接 `scale=1`，使用 Nearest 过滤。
- `metadata.json`：每帧在源图（96×144）上的包围盒与锚点横坐标；换算到 72×108 游戏帧时按 0.75 比例缩放。

## 动画及锚点

- 顺序：01 → 02 → 03 → 04 → 循环，每帧 150 ms，约 6.67 FPS。
- 各帧固定画布和脚底基准，游戏版脚底约 Y=104；可用脚底落点作 AnimatedSprite2D 的 offset。
- Godot 使用 CanvasItem.TEXTURE_FILTER_NEAREST（或纹理导入设最近邻）；尽量使用一致的画面缩放倍率。
- 面向左/右时，原画是独立朝向而非简单双向镜像；角色发型保持参考稿外观。（注：当前 player.gd 用 facing.scale.x 翻转朝向，只用一侧也能跑，两侧都留着按需取用。）

## 已知限制

这是一套对 AI 参考稿执行像素化、统一调色和自动抠图后的游戏测试素材，不是专业像素画师在 30×128 原始参考网格上逐格重画。总体像素规格统一，但近看仍可能有少数边缘像素与局部动作需要人工修整。游戏内目标身高如果必须**严格等于** 96px，请手工逐格微调所有方向，不宜通过逐帧不同缩放来强行凑高度。
